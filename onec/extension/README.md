# Расширение 1С:УНФ — интеграция с сервисом генерации аватаров

Полноценный `.cfe`-файл нельзя собрать вне платформы 1С:Предприятие, поэтому здесь —
**исходный код на BSL**, который добавляется в расширение через Конфигуратор.
Это стандартная практика хранения конфигураций 1С в git (аналог `.cf`/`.cfe` в текстовом виде).

## Состав

| Файл | Куда вставить в Конфигураторе |
|---|---|
| `src/ИнтеграцияГенерацияАватаров.bsl` | Новый общий модуль расширения (см. настройки ниже) |
| `src/ФормаСотрудникаРасширение.bsl` | Модуль расширяемой формы `Справочник.Сотрудники.ФормаЭлемента` |
| `src/ПримерХраненияФайлов.bsl` | Две функции добавить в конец **того же** общего модуля `ИнтеграцияГенерацияАватаров` (область `ПрограммныйИнтерфейс`) |

## Шаг за шагом (5–10 минут)

1. **Конфигуратор → Конфигурация → Расширения → Добавить.**
   Имя: `ГенерацияАватаров`, назначение — «Дополнение».
2. **Общие модули → Добавить.** Имя `ИнтеграцияГенерацияАватаров`.
   Свойства модуля: `Сервер = Истина`, `Клиент (управляемое приложение) = Ложь`,
   `Внешнее соединение = Истина`, `Повторное использование = Не использовать`.
   Вставьте содержимое `src/ИнтеграцияГенерацияАватаров.bsl`, затем допишите в конец
   области `ПрограммныйИнтерфейс` две функции из `src/ПримерХраненияФайлов.bsl`,
   поправив запрос под то, как в вашей базе хранятся фото сотрудников.
3. **Константы** (Общие → Константы → Добавить, тип Строка, длина не ограничена):
   - `АватарыURLСервиса` — например, `https://avatars.mycompany.local` (адрес, где развёрнут сервис из корня репозитория, порт из `.env` → `API_PORT`);
   - `АватарыAPIKey` — значение переменной `API_KEY` из `.env` сервиса.
   Задайте значения через Конфигуратор → Сервис → Параметры или из формы констант в режиме 1С:Предприятие.
4. **Права доступа**: разрешите использование интернет-ресурсов для рабочего сервера 1С
   (в кластере серверов 1С список разрешённых адресов может быть ограничен — добавьте туда хост сервиса).
5. **Форма сотрудника**: расширяемый объект `Справочник.Сотрудники`, расширяемая форма
   `ФормаЭлемента`. Добавьте команду `СоздатьАватар` (заголовок «Создать корпоративный аватар»)
   на командную панель формы и вставьте код формы из `src/ФормаСотрудникаРасширение.bsl`.
   При необходимости добавьте на форму поле выбора стиля (`corporate` / `brand` / `cartoon`) —
   список стилей можно один раз загрузить через `GET /api/v1/styles`.
6. Сохраните и подключите расширение к базе — готово.

## Как это работает

`СгенерироватьАватарИДождаться` — синхронная обёртка: отправляет фото (`POST /api/v1/avatars`),
затем опрашивает `GET /api/v1/avatars/{id}` каждые 3 секунды до статуса `done` / `failed` / `rejected`,
скачивает результат (`GET /api/v1/avatars/{id}/image`) и возвращает двоичные данные PNG.
Если нужен неблокирующий вариант — используйте `ОтправитьФотоНаГенерацию` +
регламентное задание, которое периодически обходит незавершённые задания через
`ПолучитьСтатусЗадания` (шаблон легко собрать из тех же функций).

Все обращения идут через стандартные объекты платформы `ИнтернетСоединение`/`HTTPЗапрос`
и `ЗаписьJSON`/`ЧтениеJSON` — внешние компоненты и библиотеки не требуются.

## Проверка без реальной базы 1С

Быстро проверить сам сервис можно `curl`-ом (см. корневой `README.md`, раздел «Быстрый старт»)
или через Swagger `/docs` — 1С обращается к тем же самым эндпоинтам.
